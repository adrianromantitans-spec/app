# Social brand vectors

Unmodified source SVGs downloaded on 19 November 2026 from Bootstrap Icons:

- https://github.com/twbs/icons/blob/main/icons/whatsapp.svg
- https://github.com/twbs/icons/blob/main/icons/telegram.svg
- https://github.com/twbs/icons/blob/main/icons/instagram.svg
- https://github.com/twbs/icons/blob/main/icons/snapchat.svg

Bootstrap Icons is distributed under the MIT license; the copied license is in LICENSE.txt. These are Bootstrap's vector representations of the brand marks, not files published directly by the four companies. Brand names/logos belong to their respective owners.

The exact path geometry is shared in invitation-share.js (16×16 viewBox). Web and React Native render it with explicit fills, Instagram's color gradient and a white Snapchat underlay/yellow button. No font/icon dependency or external asset request is required at runtime.
